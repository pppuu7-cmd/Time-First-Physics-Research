# Time-First-Physics-Research (TFPR)

Исследование гипотезы о первичности временной структуры по отношению к пространству, материи и взаимодействиям.

**Итерация 001, 2026-11-08: направление выбрано условно. Физическая теория не установлена.**

Основная линия — причинно-временные отношения между абстрактными событиями и условия возникновения геометрии. События, частичный порядок и счёт признаны дополнительными предпосылками; тезис «буквально всё из одного числового времени» не доказан. Активная запасная линия не открыта.

## Что сделано и что не сделано

Выполнены адресный обзор, концептуальный выбор и формальная постановка. Собственные элементарные логические проверки не называются независимой критикой. В источниках установлено условное конформное восстановление для подходящих континуальных многообразий; оно не является выводом пространства из нашего конечного порядка.

Не получены геометрический континуальный режим TFPR, материя, квантовая динамика, численные физические предсказания или экспериментальное подтверждение. Конечность времени Вселенной и конечная жизнь всех состояний не введены как законы.

**Единственный следующий объект: TFPR-ID-001 — аналитическая проверка точной идентифицируемости геометрии по конечным временным данным. Статус: PLANNED_NOT_EXECUTED.** Конкретный контрпример ещё не построен. Условия и отрицательные контроли находятся в контракте.

## Исполнение и публикация

Научных вычислений, workflows, checkpoints, новых расписаний и фоновых циклов нет. Будущие численные задачи разрешены только на стандартных GitHub-hosted runners этого публичного репозитория, с проверкой ресурсов и восстановимости. Домашние/self-hosted исполнители и платные larger runners не используются.

До публикации репозиторий проверен: содержимое и ветки отсутствовали, API Actions показывал ноль runs. Метаданные GitHub подтверждали право push. Фактический dispatch Actions не проверялся. История первого пакета сохраняется последовательными коммитами; точный научный опорный commit и blob-идентификаторы записываются в recovery.

Проверка сохранности commit/blob не является научной рецензией. Отдельная независимая критика — будущий этап. После завершения итерации 001 автоматического перехода к следующей нет.
